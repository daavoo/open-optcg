# Code of conduct

## The short version

Be decent to each other. This is a card-game simulator; nothing here is worth
being unpleasant over.

## What is expected

- Assume the person on the other side is trying to help. A bug report that turns
  out to be a rules misunderstanding is still a useful bug report — the rules are
  genuinely hard, which is why this engine exists.
- Argue about the rules, the code and the numbers, not about the person. "This
  misreads the printed text, here is the ruling" is a good comment; "you clearly
  don't play this game" is not.
- Accept that maintainers say no. A deck, a mechanic or a refactor can be right
  and still not be something anyone has time to maintain.
- Keep it about the project. Politics, recruiting and self-promotion belong
  elsewhere.

## What is not

Harassment, discrimination or slurs of any kind; sexual language or imagery;
personal attacks; deliberately derailing threads; publishing anyone's private
information. Any of these gets your comment removed and, if it continues, gets
you blocked from the repository.

## Reporting

Email the maintainer at the address on the commits in `git log`, or use GitHub's
report feature. Reports stay private. Enforcement is a judgement call by the
maintainer, and the bias is toward keeping the project a place people want to
contribute to rather than toward process.

This document is deliberately short and specific rather than an adopted
boilerplate text. If you would rather read the long form, the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
describes the same expectations.
